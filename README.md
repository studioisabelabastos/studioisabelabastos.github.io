# Studio Isabela Bastos

Site estático em português para o Studio Isabela Bastos. Não requer build nem instalação de dependências.

## Publicar no GitHub Pages

1. Envie estes arquivos para a branch principal do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch principal e a pasta **/(root)** e salve.
4. Aguarde a publicação; o GitHub exibirá o endereço do site nessa página.

Os dados de contato, endereço e formas de pagamento foram inseridos a partir das informações fornecidas. Revise os links e o endereço antes de publicar.

As fotos da seção “O studio” ficam em `images/`. Mantenha os nomes dos arquivos, incluindo a extensão `.PNG`, como estão para que carreguem corretamente no GitHub Pages.
